# College Portal — Web Technology Lab (BCS552)

A multi-module project built while learning **Web Technologies** as part of 
the AKTU BCS552 Web Technology Lab syllabus. Each module explores a 
different technology from the syllabus, unified under a single 
"College Portal" theme.

## 🎯 Purpose
This repo demonstrates hands-on implementation of core web technologies:
HTML, CSS, JavaScript, XML, Java Bean, Node.js, MongoDB, and Servlet/JSP.

## 📁 Modules

| Folder | Technology | Description |
|---|---|---|
| `01-frontend-html-css-js` | HTML, CSS, JS | Institute website, registration form with validation, responsive design |
| `02-xml-data` | XML, DTD, XSL | Course catalog data with schema validation and styling |
| `03-java-bean` | Java Bean | Employee/Faculty info bean |
| `04-nodejs-cli` | Node.js | CLI utility for admin tasks |
| `05-mongodb-aggregation` | MongoDB | Aggregation queries on student/user data |
| `06-servlet-cookie-auth` | Servlet | Cookie-based login authentication |
| `07-servlet-jsp-db` | Servlet + JSP | User registration & login connected to database |
| `08-shopping-cart-session` | Servlet | Shopping cart using session tracking |

## 🛠️ Tech Stack
HTML5, CSS3, JavaScript, XML/DTD/XSLT, Java (Servlet, JSP, JavaBeans), 
Node.js, MongoDB, Apache Tomcat
